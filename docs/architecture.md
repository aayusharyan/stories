# Architecture

## Overview

The site is generated by [Eleventy](https://www.11ty.dev/) 3 (ES modules) with **EJS** templates and **Markdown** articles. There is no server-side code at runtime and `npm run build` writes plain HTML/CSS/JS to `public/`, which can be hosted anywhere.

```
 Markdown posts ─┐
 EJS pages ──────┤
 _data/*.json,js ┼──►  Eleventy  ──►  public/   (static site)
 layouts/        │   (eleventy.config.js)
 components/ ────┘
 assets/  ───────────────────── copied as-is ──►  public/assets/
```

## Repository layout

| Path                                                | What lives here                                                               | Processed by Eleventy?                   |
| --------------------------------------------------- | ----------------------------------------------------------------------------- | ---------------------------------------- |
| `eleventy.config.js`                                | All build configuration, helpers, collections                                 | Config (read first)                      |
| `src/pages/`                                        | **Input directory.** Pages, archives, feed, sitemap, robots, and `posts/*.md` | Yes, each file becomes output            |
| `src/pages/posts/`                                  | Articles in Markdown                                                          | Yes                                      |
| `src/layouts/`                                      | `base.ejs` (generic pages), `post.ejs` (articles)                             | Yes, wraps pages                         |
| `src/components/`                                   | EJS partials (`head`, `header`, `footer`, `sidebar`, cards, ...)              | Included by layouts/pages                |
| `src/_data/`                                        | Global data: `site.json` (`site`), `build.js` (`build`)                       | Loaded into every template               |
| `src/assets/`                                       | CSS, JS, fonts, images, vendor plugins                                        | **Copied unchanged** to `public/assets/` |
| `public/`                                           | Generated output (git-ignored)                                                | Output                                   |
| `docs/`                                             | This documentation                                                            | No                                       |
| `documentation/`, `html_template/`                  | Original theme download, reference only                                       | Ignored via `.eleventyignore`            |
| `README.md`, `LICENSE.md`, `THIRD_PARTY_NOTICES.md` | Project and licence information                                               | No                                       |
| `package.json`                                      | Dependencies, `npm` scripts, Node version (`engines`)                         | No                                       |
| `.eleventyignore`, `.gitignore`                     | Files Eleventy skips / Git ignores                                            | No                                       |

Directory settings are declared in the object returned by `eleventy.config.js`:
`input: src/pages`, `includes: ../components`, `layouts: ../layouts`, `data: ../_data`, `output: public` (relative paths are resolved from `input`).

## How a page is built

1. **Discovery.** Eleventy scans `src/pages/`. Every `.ejs`, `.md`, and `.11ty.js` file is a template.
2. **Data cascade.** For each page Eleventy merges, in increasing priority: global data (`site`, `build`, `helpers`, collections) then the layout's and page's front matter.
3. **Rendering.** The page body is rendered (EJS is also enabled inside Markdown), and the layout named by `layout:` wraps it. The body is available to the layout as `content`.
4. **Includes.** Layouts call `include('components/name.ejs', { ...args })`. The `ejs.resolveInclude` override in `eleventy.config.js` resolves those names relative to `src/`.
5. **Output.** The `permalink` decides the file path, e.g. `/categories/food/index.html`.

### Page inventory

| Source                          | Output URL                                          | Layout     | Notes                                          |
| ------------------------------- | --------------------------------------------------- | ---------- | ---------------------------------------------- |
| `pages/index.ejs`               | `/`                                                 | `base.ejs` | Hero carousel, latest six posts, category grid |
| `pages/blog/index.ejs`          | `/blog/`, `/blog/page/N/`                           | `base.ejs` | Paginated (6 per page)                         |
| `pages/categories/index.ejs`    | `/categories/`, `/categories/page/N/`               | `base.ejs` | Category directory, paginated (12 per page)    |
| `pages/categories/category.ejs` | `/categories/<slug>/`, `/categories/<slug>/page/N/` | `base.ejs` | Category archive, paginated (6 posts per page) |
| `pages/tags/index.ejs`          | `/tags/`, `/tags/page/N/`                           | `base.ejs` | Tag directory, paginated (48 per page)         |
| `pages/tags/tag.ejs`            | `/tags/<slug>/`, `/tags/<slug>/page/N/`             | `base.ejs` | Tag archive, paginated (6 posts per page)      |
| `pages/posts/*.md`              | `/posts/<filename>/`                                | `post.ejs` | Articles; URL slug is the filename             |
| `pages/404.ejs`                 | `/404.html`                                         | `base.ejs` | Not-found page                                 |
| `pages/feed.xml.11ty.js`        | `/feed.xml`                                         | none       | RSS, 20 newest posts                           |
| `pages/sitemap.xml.11ty.js`     | `/sitemap.xml`                                      | none       | All pages ending in `/`                        |
| `pages/robots.txt.ejs`          | `/robots.txt`                                       | none       | Allow all + sitemap link                       |

> **Why do posts URLs start with `/posts/`?** The `posts` folder sits directly in `src/pages`, so Eleventy's default permalink is `/posts/<filename>/`. Code such as `related` matching and the `og:type` check in `head.ejs` rely on this prefix. Do not move posts elsewhere without updating those.

## Where things come from (quick "who does what")

| I want to change...                                         | Edit                                                        |
| ----------------------------------------------------------- | ----------------------------------------------------------- |
| Site name, description, URL, author bio, menu, social icons | `src/_data/site.json`                                       |
| Copyright year                                              | Automatic, from `src/_data/build.js`                        |
| Content of the `<head>` (meta tags, CSS list, JSON-LD)      | `src/components/head.ejs`                                   |
| Header / navigation markup                                  | `src/components/header.ejs`                                 |
| Footer                                                      | `src/components/footer.ejs`                                 |
| Article page structure                                      | `src/layouts/post.ejs`                                      |
| Sidebar widgets                                             | `src/components/sidebar.ejs`                                |
| Article card design                                         | `src/components/post-card.ejs` + `assets/css/post-card.css` |
| Slug rules, dates, collections                              | `eleventy.config.js`                                        |
| Colours, typography, spacing                                | `src/assets/css/base.css` (and per-component CSS)           |

## Technology stack

| Piece                               | Purpose                                             |
| ----------------------------------- | --------------------------------------------------- |
| Eleventy `^3`                       | Static site generator                               |
| `@11ty/eleventy-plugin-ejs` + `ejs` | EJS template support                                |
| Bootstrap 4.3.1 (CSS + bundle JS)   | Grid and base components (vendored in `src/assets`) |
| Font Awesome 4.7.0                  | Icons (`fa fa-<name>`)                              |
| jQuery 1.12.1, Owl Carousel         | Theme behaviour (vendored)                          |
| IBM Plex Sans + Quicksand           | Self-hosted headings and body text                  |
